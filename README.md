# ระบบจองสนามแบดมินตัน / Badminton Court Booking System

เว็บไซต์จองสนามแบดมินตันที่ใช้งานง่าย สามารถจัดการการจองสนามได้อย่างสะดวกรวดเร็ว

A simple and easy-to-use badminton court booking website for managing court reservations efficiently.

## ✨ ฟีเจอร์หลัก / Features

- 🏸 **จองสนาม** - เลือกสนาม วันที่ และเวลาที่ต้องการ
- 📅 **เลือกวันที่** - เลือกวันที่จองล่วงหน้าได้
- ⏰ **เลือกเวลา** - มีช่วงเวลาให้เลือกตั้งแต่ 08:00 - 21:00 น.
- 👥 **จัดการการจอง** - ดูรายการจองทั้งหมดและยกเลิกการจองได้
- 🔍 **กรองข้อมูล** - ค้นหาการจองตามวันที่
- 💾 **บันทึกข้อมูล** - ข้อมูลการจองจะถูกบันทึกใน Local Storage
- 🎨 **UI สวยงาม** - ออกแบบด้วย Gradient สีม่วงน้ำเงินที่ทันสมัย
- 📱 **Responsive** - ใช้งานได้ดีทั้งบนมือถือและคอมพิวเตอร์

## 🚀 วิธีใช้งาน / How to Use

1. **เปิดเว็บไซต์**
   ```bash
   # เปิดไฟล์ index.html ด้วย Web Browser ของคุณ
   # Open index.html with your web browser
   ```

2. **จองสนาม**
   - เลือกสนามที่ต้องการ (มีให้เลือก 4 สนาม)
   - เลือกวันที่ที่ต้องการจอง
   - เลือกช่วงเวลา (แต่ละช่วง 1 ชั่วโมง)
   - กรอกชื่อและเบอร์โทรศัพท์
   - กดปุ่ม "จองสนาม"

3. **ดูรายการจอง**
   - รายการจองทั้งหมดจะแสดงทางด้านขวา
   - สามารถกรองตามวันที่ได้
   - กดปุ่ม "ยกเลิกการจอง" เพื่อลบการจอง

## 📋 รายละเอียดระบบ / System Details

### สนามที่มีให้บริการ / Available Courts
- สนาม 1
- สนาม 2

### เวลาให้บริการ / Operating Hours
- เปิดบริการ: 08:00 - 21:00 น.
- แต่ละช่วงเวลา: 1 ชั่วโมง
- จองได้ทีละ 1 ช่วงเวลา

### ข้อจำกัด / Limitations
- ไม่สามารถจองสนามซ้ำในวันและเวลาเดียวกันได้
- ข้อมูลจะถูกเก็บใน Local Storage ของ Browser
- ข้อมูลจะหายหากทำการ Clear Browser Data

## 🛠️ เทคโนโลยีที่ใช้ / Technologies Used

- **HTML5** - โครงสร้างเว็บไซต์
- **CSS3** - การออกแบบและจัดรูปแบบ (Gradient, Flexbox, Grid)
- **JavaScript (ES6+)** - ฟังก์ชันการทำงานและจัดการข้อมูล
- **Local Storage** - การเก็บข้อมูลในเครื่อง

## 📱 การใช้งานบนมือถือ / Mobile Support

เว็บไซต์รองรับการใช้งานบนมือถือและแท็บเล็ต (Responsive Design)
